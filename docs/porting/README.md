# HBM Forge 1.20.1 port

The parity baseline is commit `9d7b7ca3bc999b7909fdb349738d305dff58bd7d` on the 1.7.10 `master` branch. This branch builds only `src/forge120`; the original `src/main` implementation remains as a reference. The old Gradle properties are preserved in `gradle-1.7.10.properties`.

`legacy-inventory.csv` is a source-linked audit index. Generate it with `python tools/porting/build_inventory.py` and verify it with `--check`. Put implementation status and evidence in `status.csv`; do not edit the generated inventory directly. `partial` means the content exists but its original behavior or acceptance checks are incomplete. `verified` requires a runtime or asset comparison check, not merely a compiled class. The scanner covers every legacy Java file and asset and identifies direct and helper-registered blocks, config-option and recipe-definition call sites, including the central `CraftingManager.addRecipeAuto` calls. It remains a static candidate list, not an exhaustive inventory of conditional, loop-generated, or JSON-loaded runtime recipes. Screen and worldgen source files likewise need individual behavior checks before their categories can be declared complete. See [the parity and acceptance matrix](parity-matrix.md).

## Local two-client smoke

`tools/porting/multiplayer_smoke.py` prepares an isolated `run-multiplayer` world and an independent `HbmObserver` client profile. Its server binds gameplay and RCON to 127.0.0.1. The RCON password is generated only in the ignored runtime directory; the helper refuses a different host, port or world name. After agreeing to the Minecraft EULA, prepare and start the server:

```sh
python tools/porting/multiplayer_smoke.py prepare --accept-eula
./gradlew runServer -PhbmMultiplayer --no-daemon
```

In separate terminals run the normal client and the observer, then join 127.0.0.1:25566. The observer can join directly with the optional `-PhbmAutoJoin` property. The first observer profile limits render/simulation distance and FPS for concurrent testing; the ordinary client settings are preserved.

```sh
./gradlew runClient --no-daemon
./gradlew runMultiplayerClient -PhbmAutoJoin --no-daemon
```
