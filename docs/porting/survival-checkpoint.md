## Reproduction

Run `python tools/porting/prepare_checkpoint.py prepare` once and retain its generated session. Launch `runSurvivalClient -PhbmCheckpointDriver=<session>`, create the named seed in Survival with cheats enabled, and run `prepare_checkpoint.py install-pack`. In that isolated world, reload and invoke `hbm_checkpoint:progression_setup` once; it is guarded against repeated supply grants. Resume later with `-PhbmCheckpointResume`.

`checkpoint_walkthrough.py` provides staged ordinary-action checks. Inspect each result before continuing; successful stages and their reports must not be replayed. Native anvil stamp clicks are performed between `prepare-stamps` and `press-inputs`. `start-blast`/`finish-blast`, `craft-casting-tools`, `place-casting`, `collect-casts`, `craft-and-charge`, `start-smelt` and `finish-smelt` cover the remaining route. Stop the client after `start-smelt` for the `active` audit, restart without reseeding, then finish the smelt and stop for the `complete` audit. A camera look is settled before directional placement so its normal rotation packet reaches the server first.
